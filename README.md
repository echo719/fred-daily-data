# fred-daily-data

Data for https://daily.dsh-plugin-hub.com/ (每日精进：英语 / 宏观 / AI 生命科学).

`site.html` is the whole page (data inlined). The Cloudflare Worker `fred-daily-site` fetches it from
raw.githubusercontent.com and serves it, so updating the site = pushing a new `site.html` here.
Generated by `11-每日精进/scripts/build_web_data.py` + `build_worker.py` in the owner's Obsidian vault.
